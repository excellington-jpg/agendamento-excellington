Termos de Uso e Responsabilidade

Bem-vindo ao Agendamento Excellington!

Este aplicativo armazena todos os seus dados de agendamentos e configurações exclusivamente no armazenamento interno (localStorage) do seu dispositivo atual.

⚠️ ATENÇÃO CRUCIAL:

Se você limpar o histórico, os dados de navegação, desinstalar o navegador sem backup ou usar ferramentas de limpeza agressivas, todos os seus dados serão permanentemente apagados.

Recomendamos realizar o backup regular dos seus dados utilizando o botão de exportar dados no painel de configurações.

O uso contínuo requer uma contribuição mensal voluntária via Pix para manutenção do software.
